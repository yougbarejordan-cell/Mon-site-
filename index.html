❓ Questions fréquentes

Comment ça marche ?

Choisissez un titre, payez par mobile money, envoyez-nous votre reçu sur WhatsApp, puis débloquez-le avec le code à 6 chiffres que nous vous envoyons.

Quels moyens de paiement acceptez-vous ?

NITA, AMANA TA, WAVE, Zcash, Airtel Money et Flooz.

Quels sont les prix ?

Combien de temps pour recevoir mon code ?

Dès que nous avons vérifié votre reçu sur WhatsApp, nous vous envoyons votre code. Plus votre message est complet (nom, numéro, référence), plus c’est rapide.

Puis-je regarder et télécharger mes titres ?

Oui. Une fois le titre débloqué, vous pouvez le regarder ou le télécharger depuis sa fiche, et le retrouver à tout moment dans « Mes achats ».

Comment installer l’application sur mon téléphone ?

Ouvrez les Paramètres puis touchez « Télécharger l’application ». Sur iPhone, utilisez le bouton Partager de Safari puis « Sur l’écran d’accueil ».

Mon code ne marche pas, que faire ?

Le code est lié au titre et au numéro de téléphone indiqués lors du paiement. Vérifiez ce numéro, puis écrivez-nous sur WhatsApp si le problème continue.

J’ai changé de téléphone, vais-je perdre mes achats ?

Vos achats sont enregistrés sur l’appareil. Si vous changez de téléphone, écrivez-nous sur WhatsApp avec votre preuve de paiement : nous pourrons vous aider à les retrouver.
